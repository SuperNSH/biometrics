# nsh-biometrics

Biometric and device-credential authentication for [Native Shell](https://nsh.dev) apps, in Rust and TypeScript: Face ID and Touch ID, Android biometrics, Windows Hello, and the Linux desktop's own prompt through polkit. Its API follows Flutter's [`local_auth`](https://pub.dev/packages/local_auth), and its native work builds on [`robius-authentication`](https://github.com/project-robius/robius).

This is under construction. `docs/brief.md` describes what is being built.
